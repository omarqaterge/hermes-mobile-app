# Where the name Hermux replaces Hermes

**Decided:** 2026-11-02, by the owner.

The app is Hermux. The owner reviewed the places where the name was a judgement call and chose Hermux for these, even
where the text describes what the agent does, so people meet one name there.

**So:**
- Every notification says Hermux: titles, text, fallback titles, the reply field, channel descriptions and the
  read-aloud player.
- Settings' section and the "Uninstall Hermux" row, sheet and prompt say Hermux, and so do the drawer tile and the page
  it opens.
- ~~Other text about the agent still says Hermes for now ("Hermes is thinking", "Hermes settings", "Message Hermes").~~
  Replaced on 2026-11-02, see below.

**Changed 2026-11-02, by the owner:** people see only Hermux in the app. Every on-screen mention of the agent says
Hermux too ("Hermux is thinking", "Hermux settings", "Message Hermux", "Give Hermux full access?"), and so do the
Android strings, the plugin's messages that reach the app or a chat, and the phone scripts' output shown in the app or
in Termux.

**So:**
- New on-screen text says Hermux, never Hermes.
- Hermes stays only where people don't read it as the app's name, or where Hermux would be untrue: code identifiers,
  file, class and folder names, the package ID, `localStorage` keys, bridge method names, paths such as
  `/root/.hermes`, the `hermes` command, the plugin folder `hermes-mobile`, the APK file `hermes-mobile.apk`, the
  update address checks ([hermux-name-update-path.md](hermux-name-update-path.md)), credits and links to the upstream
  project, and the instruction to install Hermes Agent itself.
- The phone folder `Pictures/Hermes` keeps its name (the app saves there and the text names the real folder), and so
  do the old name in README's top picture and the released sections of CHANGELOG.md, until the interface redo.
