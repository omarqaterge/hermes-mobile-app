# Where the Pairing notification shows up

**State:** Start pairing (Setup → Shizuku starts by itself) asks the user to type the Wireless debugging code into the
app's "Pairing" notification. On some phones that notification gets no heads-up and sits folded low in the shade, with
the code field hidden until it is expanded. A split-screen fallback was offered to the owner; not decided.

**Next:** the owner's decision; until then, nothing to build.

**Needs a real phone:** yes, phones whose system UI hides heads-up notifications.
