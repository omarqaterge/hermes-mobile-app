# Ranked improvements (review of 2026-09-30)

A full read of the app (web UI, Android shell, plugin, phone scripts) and of the gateway contract, ranked by
value in daily use × confidence ÷ effort, with real bugs counted extra. Effort: S = under an hour, M = a few hours,
L = a day or more. **Status:** `web ✓` = done in the web code and passing `tools/web-e2e`, but NOT yet installed or
tried on the phone; `open` = not started.
