- **Adding a model provider is one clear button.** Settings → Models is now one page: the model new chats use, the
  providers you have connected, a gold "Add a provider" button, the fallback models folded under "If the model fails",
  and All keys last. Add a provider lists what you can still connect: sign in with an account you have, use an API key,
  or your own server. When the bot has no model yet, connecting a provider opens the model list for it at once, and
  choosing one is all it takes. A new chat with no model says "No model connected yet" with a Connect a model button
  under the Hermux mark, and the chat's model list has "Add a provider" as its last row. Checked in a desktop browser
  against a test copy of Hermux. Not yet tried on a phone.
