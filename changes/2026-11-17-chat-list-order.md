- **The chat you used last is at the top of the list.** The side panel's chats and their day groups (Today, Yesterday,
  This week…) now follow when each chat was last active, not when it was made, so a chat you picked up again this
  morning is under Today. Rows never jump while you look at the list: the order is read when the panel opens, and a
  reply that lands meanwhile only changes that row's line. Your own order (after dragging a chat) and pinned chats stay
  exactly as they are.
- **Each chat says whether it is working or finished.** The line under a chat's title shows the time and then
  "Working" while Hermux runs it or "Finished" when it has a reply you have not opened, instead of the number of
  messages. A scheduled job's run shows the job's name with a clock instead of "cron". Checked in a desktop browser;
  not yet on a phone.
