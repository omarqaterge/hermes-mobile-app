- **Hermes settings, in plain words.** Settings → Hermes settings is a new page with 60 of Hermes's own options that matter on a phone, in groups: when a model fails, replies, memory, long chats, sub-agents, web and tools, safety and privacy, and chats and housekeeping. Each option says in one line what it does, uses a proper switch, list or number field with its limits ("Between 0 and 10"), shows a "Changed" tag when it differs from Hermes's default, and has "Use default" to go back. Every other option is still under Advanced settings by its config name. Checked in the browser tests against a mock with the pinned Hermes's defaults; not yet seen on a phone.
