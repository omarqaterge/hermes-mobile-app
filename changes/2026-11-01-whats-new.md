- **What's new before you update.** When a newer version is available, Settings → About shows a "What's new" row under "Update to …". It opens the changes of every version since the one you have (newest first, so skipped versions are included), with an Update button at the bottom. The text comes from the release's changelog on GitHub; if it can't be read, the row is left out and updating works as before. Web tests only; not yet on a real phone.
