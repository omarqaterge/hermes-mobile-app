- **Other apps can no longer make Hermux read its own private files.** Sharing to Hermux now accepts only files that another app hands over as a normal shared file; a share that points at Hermux's own stored data or its own camera folder is ignored, and the file shows "can't be shared". The ways Hermux's own notifications and launcher shortcuts open a chat, fill the message box, start an update or ask for the unlock screen can no longer be used by other apps: those requests are only honoured when Hermux itself sent them. Limits: another app can still open a new chat or start Live mode through the launcher shortcuts and the assistant intent (Live mode still needs the unlocked phone), and notifications or the "last chat" shortcut made by an older version open the app without opening the chat until they are posted or made again (the shortcut heals itself the next time a chat is opened). Checked: the address check runs in `tools/test_share_uri.sh` and in CI. The Android code could not be compiled in this environment and nothing was tried on a phone.
